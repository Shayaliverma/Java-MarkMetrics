# MarkMetrics — Student Performance Analyzer

MarkMetrics is a Java console-based application that analyzes student marks using arrays and basic programming concepts.

## Features

* Accepts marks for multiple subjects
* Validates marks between 0 and 100
* Calculates total marks
* Calculates average marks
* Finds the highest mark
* Finds the lowest mark
* Handles invalid input by asking the user to enter the mark again
* Displays results in a clean and professional format

## Concepts Used

* Java
* Arrays
* `for` loop
* `for-each` loop
* `while` loop
* `if` condition
* User input using `Scanner`
* Type casting
* Basic mathematical calculations

## How to Run

### 1. Compile the program

```bash
javac Main.java
```

### 2. Run the program

```bash
java Main
```
